# CodeBooks - Python Beginner to Advanced

## E-book Selling Landing Page

This project is a simple and responsive e-book selling landing page created using HTML5 and CSS3.

## Features

- Header with navigation menu
- Hero section
- E-book cover
- About section
- What You Will Learn section
- Feature cards
- Pricing section
- Order form
- Customer reviews
- FAQ section
- Footer with contact information and social media links
- Responsive mobile design
- Buy Now hover effects

## Technologies Used

- HTML5
- CSS3
- Flexbox
